# 美术生图提示词（T7 · 中文版）

> 用途：把下面每只精灵的提示词直接粘给生图模型，产出精灵立绘 / 图标。
> 说明：**不追求"生成即可直接上机"**。生成图只作为美术参考与素材来源，
> 后续怎么进游戏由我另行处理（缩放、改色、重描边、或退回程序化绘制）。
> 因此提示词重点放在**画得像、画得可爱、风格统一**，不堆砌技术限制。

---

## 一、怎么用

1. 每条提示词都是**完整可直接粘贴**的，不需要你自己拼前缀。
2. 建议**先只生成小火狮一张**，看风格对不对；确认后再生其余 7 只。
3. 尺寸不用严格，正方形即可（建议 512×512 或 1024×1024，我要缩放）。
4. 生成结果存到 `E:\小说2\精灵对战小游戏\art-inbox\`，文件名见每节标注。

## 四、主角行走图（有风险，建议最后做）

4 方向 × 2 帧 = 8 张。**AI 很难保证同一角色跨 8 张保持一致**（头发长度、衣服比例都会飘），
大概率会出现走路抽搐。如果要做，让模型**一次出一整张总表**，比出 8 张单图成功率高。

→ `player_sheet.png`
```
像素风游戏角色行走图总表，复古像素画风格。一张 4 行 2 列的网格总表，
每格一个 16×16 像素大小的同一角色：一个戴帽子的小男孩，蓝色上衣、深色裤子，
背着一个棕色小背包。四行分别是面朝下、面朝上、面朝左、面朝右，
每行两格是同一方向的站立帧与迈步帧。八个格子的角色必须完全一致，
只有朝向和腿部姿势不同。网格排列整齐、格子等大、每格居中。
纯色浅背景，每个角色外轮廓一圈深色描边，硬边缘无抗锯齿。
不要文字、不要序号、不要网格线之外的分隔装饰、不要水印。
```

## 五、地图图块（可选，不建议交给 AI）

草地 / 草丛 / 树 / 水 / 道路 / 房屋墙 / 门 / 岩壁 / 高地 / 花丛，共 10 种 16×16 图块。
这类东西**程序化绘制本来就更合适**（要严丝合缝地拼接、颜色要卡准），
AI 生成的图块很难做到无缝平铺。当前程序化图块已经完全可用，建议保持现状。

如果确实想试，可以让模型出一张 5 列 2 行的图块总表 → `tileset_sheet.png`：
```
像素风游戏地图图块总表，5 列 2 行共 10 个 16×16 像素图块，等大整齐排列：
草地、深色草丛、树、水面、土路、砖墙、木门、岩石、高地、花丛。
每个图块要能上下左右无缝平铺，颜色统一自然，硬边缘无抗锯齿，
不要文字、不要序号、不要水印、不要阴影。
```

## 六、风格统一的三个小建议

1. **同一只精灵的立绘和图标要分两次生成**，不要指望用同一句提示词缩放。
2. 八只统一要求"正面全身、纯色背景、深色描边、块面清晰"，这样摆在一起才像一套。
3. 属性主色是**倾向参考**而非硬性限制：火偏橙、水偏浅蓝、草偏嫩绿、风偏蓝、
   光偏白、暗偏粉、雷偏亮黄。色彩稍微跑偏没关系，别整只精灵主色跑掉就行。

## 七、备用的转换工具（可选）

如果某张图恰好比较规整，可以用 `tools/art_import.py` 试着转成游戏内可用的字符画：

    C:\Users\1\AppData\Local\Programs\Python\Python312\python.exe tools\art_import.py art-inbox\creature_1_battle.png

它会抠掉背景、量化到游戏 16 色、输出字符画和 8 倍预览。
**这只是便利工具，不是本阶段的验收要求** —— 转不干净很正常，
到时按 T7 原计划用程序化字符画重绘即可。
