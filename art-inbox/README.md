# 生图投放目录

把生图模型产出的 PNG 放到这里，文件名建议：

- 精灵立绘：`creature_1_battle.png` … `creature_8_battle.png`
- 精灵图标：`creature_1_icon.png` … `creature_8_icon.png`
- 主角总表：`player_sheet.png`
- 图块总表：`tileset_sheet.png`（可选）

提示词见 `docs/美术生图提示词.md`（中文，可直接粘贴）。

尺寸不必严格，正方形即可；不必追求"生成即可直接使用"，
我会在拿到图之后处理缩放与配色，或按需退回程序化绘制。

**建议先只放 `creature_1_battle.png` 一张**看风格。
